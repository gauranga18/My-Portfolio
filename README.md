# Portfolio

Pure HTML, CSS and JS. No build step, no dependencies. Open `index.html` or deploy the folder to GitHub Pages, Netlify or Vercel.

## Customize
1. Replace "Your Name", `you@example.com` and the GitHub/LinkedIn URLs in `index.html`. Only keep social links for accounts you actually use.
2. Replace the three sample projects and their case studies with your own. If one started as a tutorial, say what you changed.
3. Update the footer repo link to your portfolio's repository.
